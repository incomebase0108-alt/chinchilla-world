# 🐭 チンチラ倉庫番（Chinchilla Sokoban）

さくらと一緒に、6色のチンチラを巣（ゴール）へ運ぶ **3D 倉庫番パズル**です。
Three.js（WebGL）製。ブラウザだけで動き、PC でもスマホでも遊べます。

🎮 **遊ぶ → https://incomebase0108-alt.github.io/chinchilla-world/**

---

## 概要

- **ジャンル**：3D 倉庫番（Sokoban）パズル
- **プレイヤー**：さくら（リアルなチンチラ）。足元のピンクの光る輪・頭上のマーカー・「さくら」ラベルで見分けられます。
- **押す対象**：6色のチンチラ（ブラウン / グレー / ホワイト / ベージュ / サファイア / バイオレット）
- **ゴール**：黄色く光る輪（＝巣）。すべてのチンチラを巣に入れたらクリア。
- **難易度**：かんたん / ふつう / むずかしい / おに（全19面）— 壁の仕掛け入りステージあり。
- **詰み防止**：チンチラを角に押し込んで動かせなくなると警告が出て、ワンタップで「もどす／やりなおし」できます。
- クリア状況は `localStorage` に自動保存され、ステージ選択に ★ が付きます。
- 収録ステージはすべて**自作ソルバー(BFS)で「解けること」を検証済み**です。

## 操作方法

| 操作 | キーボード | スマホ |
|------|-----------|--------|
| 移動 | 矢印キー / `W` `A` `S` `D` | 画面右下の十字キー |
| ひとつ戻す（Undo） | `U`（または `Z`） | HUD の「↩ もどす」 |
| やり直す（Reset） | `R` | HUD の「⟳ やりなおし」 |
| ステージ選択へ | `Esc` | HUD の「☰ 選択」 |
| 視点を回す / ズーム | マウスドラッグ / ホイール | ドラッグ / ピンチ |

※ 移動は**視点（画面）基準**です。カメラをどの角度に回しても、▲＝画面の奥（上）・▼＝手前・◀▶＝画面の左右 に進みます。

## 遊び方

1. タイトルで **難易度** を選び、**ステージ** を選びます。
2. さくらを動かして、チンチラを押します（倉庫番なので**引く**ことはできません）。
3. チンチラの向こう側が壁・別のチンチラ・行き止まりだと押せません。詰まったら **U** で戻すか **R** でやり直し。
4. すべてのチンチラを黄色い巣に入れるとクリア！手数が少ないほど★が多くもらえます。

## 技術メモ

- **Three.js 0.161**（CDN・importmap）+ `GLTFLoader` / `OrbitControls` / `SkeletonUtils`
- チンチラの 3D モデル（GLB）は `models/` にローカル同梱（外部依存なし）。
  読み込み元は `index.html` の定数 `const BASE = './models/';` で切り替えます。
- 単一の `index.html` で完結。ビルド不要。

```
chinchilla-world/
├── index.html          # ゲーム本体
├── models/             # チンチラ 3D モデル（GLB）
│   ├── player_chinchilla_grey.glb # プレイヤー（さくら・リアル）
│   ├── mob_queen_sakura.glb       # ※女王さくら（ボス用モデル・未使用予備）
│   ├── pet_chinchilla_brown.glb
│   ├── pet_chinchilla_grey.glb
│   ├── pet_chinchilla_white.glb
│   ├── pet_chinchilla_beige.glb
│   ├── pet_chinchilla_sapphire.glb
│   └── pet_chinchilla_violet.glb
└── README.md
```

## ローカルで動かす

GLB は `fetch` で読み込むため、`file://` 直開きではなくローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```
